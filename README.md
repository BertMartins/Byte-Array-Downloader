# Byte Array Downloader

Converte arrays de bytes em arquivos para download direto no navegador.

🔗 **Demo:** https://bertmartins.github.io/Byte-Array-Downloader/

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/Byte-Array-Downloader.git
cd Byte-Array-Downloader
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
